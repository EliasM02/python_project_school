# Python School Project

Terminal-based Python application created as part of a school assignment.

## Description
This program simulates basic financial calculations for a small business.
It allows the user to create invoices, calculate salary and taxes, and
generate a yearly income forecast based on CSV data.

## Code ownership
The calculations module in this project was based on an initial file written by another student.
The code was later modified, extended and integrated into the main application by me
as part of the assignment.

## Features
- Menu-driven terminal interface
- Invoice and salary calculations
- Tax calculation based on municipality and parish
- CSV file handling
- Income forecast visualization using matplotlib

## Requirements
- Python 3.10+
- matplotlib
- numpy

## How to run
1. Clone the repository
2. Install dependencies:
   ```bash
   pip install matplotlib numpy
3. Run the program:
   ```bash
   python main.py

## Project structure
- main.py – Main program and menu system
- calculations.py – Core calculation logic
- Arbetstimmar.csv – Monthly working hours data
- skattetabell.csv – Tax table data
